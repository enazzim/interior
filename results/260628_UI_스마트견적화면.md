# 🖥️ [UI 화면 설계] 스마트 견적 작성 화면 (Wireframe)

이 화면은 사장님(ADMIN)이 로그인했을 때 띄워지는 **'원가 노출형(투트랙) 견적 작성 화면'** 의 스케치입니다. 
직원(STAFF) 계정으로 로그인하면 자물쇠(🔒)가 표시된 원가 관련 영역은 화면에서 완전히 증발하여 보이지 않게 됩니다.

---

## 📌 [상단 영역] 현장 및 수금처(고객) 정보
고객 정보와 현장의 기본 뼈대를 세팅하는 영역입니다.

| 화면 항목 | 입력 방식 (UI 컴포넌트) | 화면 표시 예시 |
|---|---|---|
| **현장명** | `[ 텍스트 직접 입력 ]` | 서초 래미안 32평 올수리 |
| **수금 거래처(고객)** | `[ ▼ 콤보박스 선택 ]` | 홍길동 (Vendors 테이블에서 불러옴) |
| **공급받는 자 주소** | `[ 텍스트 자동 채워짐 (Read-only) ]` | 서울시 서초구 서초동 123-4... |
| **견적 버전** | `[ 시스템 자동 채워짐 (Read-only) ]` | 1차 견적 |

---

## 📌 [중단 영역 1] 공정별 빠른 탭 이동 (Tab Menu)
수십~수백 개의 견적 내역을 한눈에 보기 쉽게 공정별 서랍(탭)으로 분리하여 스크롤 압박을 없앱니다.

`[ 📋 전체 내역 보기 ]`  `[ 1. 철거/가설 ]`  `[ 2. 설비/방수 ]`  `[ 3. 목공사 ]`  `[ 👉 4. 타일공사 ]`  `[ 5. 도배공사 ]`

---

## 📌 [중단 영역 2] 스마트 입력 및 단위 자동 환산 그리드 (★핵심 UI)
자재를 선택하고 면적만 입력하면, 우측의 환산 수량과 원가가 실시간으로 튀어나오는 마법의 엑셀형 그리드입니다.

*(현재 **[ 4. 타일공사 ]** 탭을 클릭하여 열어둔 상태를 가정합니다)*

| [1] 자재/내역 선택 (콤보박스) | [2] 시공 면적 (수동입력) | 👉 [3] 자동 환산 발주수량 | 🔒 [4] 1단위당 원가 (자재+인건비) | 🔒 [5] 숨은 총 원가 | [6] 고객 제출용 통단가 (마진포함) | [7] 고객 제출 총액 |
|---|:---:|:---:|:---:|:---:|:---:|:---:|
| `[ 이태리 포세린 타일 600각 ▼ ]` | `[ 15 ]` ㎡ | **10 Box** *(1.5㎡/Box)* | 🔒 *20,000원 + 15,000원* | 🔒 *350,000 원* | `[ 50,000 ]` 원/Box | **500,000 원** |
| `[ 부자재 (세라픽스 본드) ▼ ]` | `[ 15 ]` ㎡ | **3 통** *(5㎡/통)* | 🔒 *15,000원 + 0원* | 🔒 *45,000 원* | `[ 25,000 ]` 원/통 | **75,000 원** |
| `[ ➕ 내역 한 줄 추가하기 ]` | | | | | | |

> **💡 UI 동작 로직 설명 (사장님 필독!)**
> - **[2]번 칸**: 현장에서 사장님이 줄자로 잰 실제 가로세로 면적(15㎡)만 키보드로 칩니다.
> - **[3]번 칸**: 입력하는 즉시, 자재 마스터에 등록된 환산 비율(1.5)을 스스로 계산해 "자재상에 타일 10박스 시켜라"라고 자동 출력합니다. (발주 실수 확률 0%)
> - **[4],[5]번 칸**: 사장님 눈에만 붉은색으로 보이는 투트랙 원가입니다. 고객에게 출력해 줄 종이 견적서에는 이 두 칸이 통째로 삭제되어 인쇄됩니다.

## 📌 [하단 영역] 마진율 대시보드 및 발행 컨트롤러
현재 마우스로 만지고 있는 이 견적서의 수익성을 실시간으로 보여주고, 최종 결과물을 출력합니다.

- **현장 예상 총 원가 (자재+인건비)** : `🔒 395,000 원`
- **고객 청구 총 견적액** : **575,000 원**
- **🔥 실시간 예상 순수익 (마진율)** : `🔒 180,000 원 ( 31.3% )`
