## 1. 메인 메뉴 및 라우터 구조도 (Navigation Menu & Router Tree)

본 시스템은 크로스 플랫폼(React + Vite + Electron) 환경에 최적화된 좌측 GNB(Global Navigation Bar) 구조를 가집니다. 라우터 파일인 `App.tsx` 및 사이드바 컴포넌트인 `Sidebar.tsx`에 실제 구현된 경로와 일치하도록 명세화되었습니다.

```
📂 루트 레이아웃 (MainLayout.tsx)
 ├── 📊 1. 대시보드 (Dashboard.tsx - `/`)
 ├── 📈 2. 상세 경영 지표 (Analytics.tsx - `/analytics`)
 ├── 🔨 3. 현장 목록 관리 (ProjectList.tsx - `/projects`)
 ├── 📝 4. 스마트 견적 시뮬레이터 (EstimateBuilder.tsx - `/estimate`)
 ├── 💵 5. 정산 및 매입 관리 (Settlement.tsx - `/settlements`)
 ├── 📜 6. 현장 이력 현황 (SettlementHistory.tsx - `/settlement-history`)
 ├── 📂 7. 마스터 데이터 관리 (MasterData.tsx - `/master`)
 └── ⚙️ 8. 시스템 설정 (Settings.tsx - `/settings`)
```

## 2. 각 메뉴별 상세 설계 및 제어 로직

### 2.1. 📊 대시보드 (`/`)
* **설계 의도:** 로그인 후 마주하는 첫 요약 장부 화면입니다.
* **주요 기능:**
  * **수익성 차트:** 현장별 미수금 현황 요약 차트 렌더링.
  * **채권 회수 긴급 보드:** 미수금 잔액이 남아있는 현장의 리스트를 실시간 경고판으로 노출.

### 2.2. 📈 상세 경영 지표 (`/analytics`)
* **설계 의도:** 확정 계약된 현장들의 경영 지표 분석 대시보드입니다.
* **주요 기능:**
  * **KPI 집계 자동 필터링:** `견적중` 상태는 제외하고 계약 체결 현장(`수주`, `공사중`, `완료`)의 금융 추이 및 마진 랭킹 분석.
  * **시각화:** `Recharts` 차트 라이브러리를 활용해 순이익 마진 랭킹, 미수금 연령(Aging) 분석, 거래처별 지출 비중, 월별 추이를 다차원 그래프로 표현.

### 2.3. 🔨 현장 목록 관리 (`/projects`)
* **설계 의도:** 영업(영업 문의 ➔ 계약 ➔ 시공 ➔ 완료) 라이프사이클을 칸반 보드 형태로 제어하는 화면입니다.
* **주요 기능:**
  * **현장 잠금 모달 (Lock):** 프로젝트의 상태가 `완료(정산)`로 설정된 카드를 클릭하여 팝업을 열면, 인풋 필드가 전면 `disabled` 처리되며 `+ 신규 견적` 및 `수정` 버튼이 숨겨집니다. 오직 `닫기` 버튼만 동작하도록 UI 상태가 동결됩니다.

### 2.4. 📝 스마트 견적 시뮬레이터 (`/estimate`)
* **설계 의도:** 면적을 입력받아 필요 유통 자재량을 자동 산출하고 엑셀 견적서를 생성하는 스마트 적산 엔진 UI입니다.
* **주요 기능:**
  * **자재 검색 자동완성:** 드롭다운이 아래 컴포넌트에 가리지 않도록 z-index를 `9999`로 지정하고 가상 스크롤을 탑재했습니다.
  * **라벨 동적 치환:** 
    * `LABOR` (노무비) 선택 시: `수량 / 투입 일수 (품)`로 라벨 치환.
    * `MATERIAL` (자재비) 선택 시: `소요 수량 (㎡)`, `소요 수량 (m)` 등으로 자재의 실측 단위에 맞춰 동적 치환.
  * **장바구니 콤마 적용:** 자재 장바구니 리스트 렌더링 시 천 단위 쉼표가 자동 매핑됩니다.

### 2.5. 💵 정산 및 매입 관리 (`/settlements`)
* **설계 의도:** 단일 현장의 '고객 실제 수금액 vs 자재상 실제 지출액' 대조를 위한 최종 결산 및 정산 화면입니다.
* **상단 KPI 5대 핵심 카드시스템:**
  1. `견적 총액`: 가장 최신 버전 견적서의 금액 합계.
  2. `실제 계약금액 (수주)`: 계약 시 합의된 최종 계약 총금액.
  3. `실제 수금액 (네고/할인)`: 통장 입금액 누계 및 할인(네고) 삭감액 표기.
  4. `실제 지출 (원가)`: 자재, 인건비 송금액 누계.
  5. `최종 순이익`: `실수금액 - 지출원가` 기반의 확정 순이익.

### 2.6. 📜 현장 이력 현황 (`/settlement-history`)
* **설계 의도:** 전체 현장의 진행 및 손익 이력을 연도별로 통합 조회하고 보존하는 장부 보관소입니다.
* **주요 기능:**
  * **동적 DB 연도 바인딩:** DB에서 실제 저장되어 있는 연도 리스트를 추출하여 콤보박스에 바인딩합니다.
  * **상단 KPI 2원화 카드:** `수주/공사/완료`의 확정 실적 합산 카드와, `견적중`인 미계약 가액(파이프라인) 카드를 분리 노출합니다.

### 2.7. 📂 마스터 데이터 관리 (`/master`)
* **설계 의도:** 자재 단가 사전, 거래처, 공정 템플릿 마스터를 관리하는 화면입니다.
* **주요 기능:**
  * **자재 등록 탭 분기:** [자재 단가] 탭과 [노무/인건비 단가] 탭으로 구분하여 인풋 및 단가 등록 폼을 분기 제공합니다. (가상 스크롤 적용 완료).

### 2.8. ⚙️ 시스템 설정 (`/settings`)
* **설계 의도:** 사내 프로필 설정 및 권한, 직원 계정을 생성 관리하는 통제실입니다.
* **주요 기능:**
  * **원가 영역 숨김 보안 (STAFF):** 로그인한 사용자의 역할이 `STAFF`인 경우, 사이드바에서 `3번 정산 메뉴`를 숨기고 원가나 마진율 관련 열람 권한을 제한합니다.

## 3. 스마트 견적 작성 화면 와이어프레임 및 명세

사장님(ADMIN)에게 노출되는 원가 노출형(투트랙) 견적 작성 화면의 컴포넌트 구성 명세입니다.

### 3.1. 화면 레이아웃 스케치 및 컴포넌트

* **[상단 영역] 현장 및 수금처 정보**
  * `현장명`: 텍스트 인풋 (예: 서초 래미안 32평 올수리)
  * `수금 거래처(고객)`: 자동완성 콤보박스 (`ClientAutocomplete.tsx` 활용)
  * `공급받는 자 주소`: Read-only 텍스트박스
  * `견적 버전`: Read-only 텍스트

* **[중단 영역 1] 공정 탭 메뉴**
  * 공정 마스터 데이터에 정렬된 순서대로 가로 정렬된 탭 (`전체`, `타일공사`, `도배공사` 등)

* **[중단 영역 2] 스마트 입력 및 단위 자동 환산 그리드 테이블**
  1. `자재/내역 선택`: 검색형 자동완성 인풋 (`MaterialAutocomplete` 컴포넌트)
  2. `시공 면적`: 수량 직접 입력 인풋
  3. `자동 환산 발주수량`: 면적을 conversionRate로 나눈 자동 올림 환산 수량 및 발주 단위 (Read-only)
  4. `1단위당 원가 (자재 + 인건비)`: `[MATERIAL]`은 purchasePrice 노출, `[LABOR]`는 laborPrice 노출 (🔒 ADMIN 전용)
  5. `숨은 총 원가`: `calculatedQty * 원가`로 누적되는 숨김 원가 (🔒 ADMIN 전용)
  6. `고객 제출용 단가`: 마진이 포함되어 견적서에 인쇄되는 최종 단가 (수동 조정 가능)
  7. `고객 제출 총액`: `calculatedQty * 고객 단가`로 계산되는 라인 합계

* **[하단 영역] 마진 요약 및 액션 버튼**
  * `현장 예상 총 원가`: `🔒 ADMIN 전용`
  * `고객 청구 총 견적액`: 마진 합산 최종 견적가
  * `실시간 예상 마진율`: `🔒 ADMIN 전용 (예: 180,000원 / 31.3%)`
  * `액션 버튼`: `[ 새 버전으로 견적서 발행 / 이 내역으로 견적서 발행하기 ]`, `[ 엑셀 다운로드 (고객용/실행용 투트랙) ]`
