# Nginx에 여러 클라이언트 프로그램 기동하기 가이드

**작성일**: 2026년 6월 30일
**작성자**: PRODEV

---

## 1. 개요
단일 AWS EC2 인스턴스에 설치된 Nginx를 활용하여, 여러 개의 독립적인 프론트엔드(React/Vite) 프로젝트를 동시에 서비스하기 위한 아키텍처 가이드입니다. 
정식 도메인이 아닌 **IP 주소 기반**으로 접속할 때 소스 코드 수정 없이 가장 빠르고 안정적으로 분리할 수 있는 **[포트 분리 방식]**을 채택했습니다.

## 2. Nginx 설정 파일 (`nginx.conf`) 작성 예시

일반적으로 Nginx 설정 파일은 리눅스 환경에서 `/etc/nginx/nginx.conf` 또는 `/etc/nginx/sites-available/default` 경로에 위치합니다.

```nginx
http {
    # 기존 기본 설정들... (include mime.types 등)

    # ─────────────────────────────────────────────
    # [프로젝트 A] - 80번 기본 포트 사용
    # ─────────────────────────────────────────────
    server {
        listen 80;
        server_name localhost; # 도메인이 없으므로 localhost 또는 언더바(_) 사용

        # 프로젝트 A의 프론트엔드 빌드(dist) 폴더 위치
        root /var/www/projectA/dist;
        index index.html;

        location / {
            # React/Vite (SPA) 새로고침 404 에러 방지용 필수 설정
            try_files $uri $uri/ /index.html;
        }

        # (선택) 백엔드(Spring Boot)로 API 요청을 포워딩할 경우
        # location /api/ {
        #     proxy_pass http://localhost:38080;
        # }
    }

    # ─────────────────────────────────────────────
    # [프로젝트 B] - 85번 포트 사용
    # ─────────────────────────────────────────────
    server {
        listen 85;
        server_name localhost;

        # 프로젝트 B의 프론트엔드 빌드(dist) 폴더 위치
        root /var/www/projectB/dist;
        index index.html;

        location / {
            # React/Vite (SPA) 새로고침 404 에러 방지용 필수 설정
            try_files $uri $uri/ /index.html;
        }

        # (선택) 만약 프로젝트 B의 백엔드가 따로 돈다면 포트 번호를 다르게 설정
        # location /api/ {
        #     proxy_pass http://localhost:8081; 
        # }
    }
}
```

## 3. 핵심 주의 사항 및 적용 방법

> [!warning] AWS EC2 보안 그룹(Security Group) 인바운드 규칙 열기
> Nginx 서버 쪽 세팅이 완벽하더라도, 외부 방화벽 역할을 하는 AWS EC2 관리 콘솔에서 **[보안 그룹 - 인바운드 규칙]**에 사용할 새로운 포트(예: TCP `85`)를 개방해 주지 않으면 외부에서 접속할 수 없습니다.

### 적용 순서
1. 위 설정 내용으로 `nginx.conf` 파일 수정
2. AWS EC2 인바운드 규칙에서 80번, 85번 포트 개방
3. 터미널에 `sudo systemctl restart nginx` 명령어 입력하여 Nginx 재시작
4. 브라우저에서 `http://[EC2_IP주소]` 및 `http://[EC2_IP주소]:85` 로 각각 정상 접속되는지 테스트
