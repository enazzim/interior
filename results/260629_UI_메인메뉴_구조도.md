# 2026-06-29 [설계도] UI 및 메인 메뉴 구조 상세 명세서

본 명세서는 크로스 플랫폼(React + Vite + Electron) 환경에서 구동되는 하이브리드 인테리어 관리 시스템의 네비게이션 메뉴 및 각 화면별 컴포넌트 설계 명세서입니다.

---

## 1. 메인 메뉴 구조도 (Navigation Menu Tree)

```
📂 루트 레이아웃 (MainLayout.tsx)
 ├── 📊 1. 대시보드 (Dashboard.tsx - `/`)
 ├── 📈 2. 상세 경영 지표 (Analytics.tsx - `/analytics`)
 ├── 🔨 3. 현장 목록 관리 (ProjectList.tsx - `/projects`)
 ├── 📝 4. 스마트 견적 시뮬레이터 (EstimateBuilder.tsx - `/estimate`)
 ├── 💵 5. 정산 및 매입 관리 (Settlement.tsx - `/settlement`)
 ├── 📜 6. 현장 이력 현황 (SettlementHistory.tsx - `/settlement-history`)
 ├── 📂 7. 마스터 데이터 관리 (MasterData.tsx - `/master`)
 └── ⚙️ 8. 시스템 설정 (Settings.tsx - `/settings`)
```

---

## 2. 각 메뉴별 상세 설계 및 제어 로직

### 2.1. 📊 대시보드 (`/`)
* **역할:** 로그인 후 직면하는 첫 메인 요약판입니다.
* **주요 기능:**
  * **수익성 차트:** 현장별 미수금, 미지급금, 실지출 대비 마진 현황을 차트 컴포넌트로 시각화
  * **진행 중인 현장 카드:** 현재 진행 중인 공정 현황 요약 및 바로가기

### 2.2. 📈 상세 경영 지표 (`/analytics`)
* **역할:** 계약 체결된 확정 현장의 금융 추이, 공정별 지출 비중, 미수금 연령(Aging) 및 현장별 마진율 랭킹 분석
* **주요 기능:**
  * 계약 확정 현장(`수주`, `공사중`, `완료`)의 금액만 확정 마진액으로 집계하여 미계약 견적의 가계산 착시를 원천 차단

### 2.3. 🔨 현장 목록 관리 (`/projects`)
* **역할:** 영업 현장을 상태별로 제어하고 모달을 띄우는 메인 제어판입니다.
* **주요 기능:**
  * **칸반 보드 (Kanban):** 현장 카드를 드래그하여 `견적중` ➔ `수주` ➔ `공사중` ➔ `완료` 상태로 손쉽게 이동
  * **현장 상세 모달 팝업 잠금 (Lock):**
    * 완료(`완료`) 상태인 현장 카드를 클릭하여 팝업을 열면, 인풋 상자들이 `disabled` 처리되어 수정이 전면 방지됩니다.
    * `+ 신규 견적` 및 `수정·새버전` 단추가 완전히 숨겨져 데이터 변조를 막으며, `수정 저장` 단추 대신 오직 `닫기` 버튼만 활성화됩니다.

### 2.4. 📝 스마트 견적 시뮬레이터 (`/estimate`)
* **역할:** 자재와 인건비를 목록화하고 엑셀 견적서를 생성하는 고생산성 단독 적산 화면입니다.
* **주요 기능:**
  * **자재 종류 선택 (자동완성):** 자재 검색 시 결과 리스트가 아래 패널에 가리지 않도록 드롭다운 z-index를 `9999` 로 최상단에 렌더링되게 해결했습니다.
  * **단위 라벨 동적 치환:** 
    * 노무비 품종 선택 시: 입력 라벨이 **`수량 / 투입 일수 (품)`**로 자동 치환
    * 일반 자재 품종 선택 시: 입력 라벨이 자재에 맞춤 연동되어 **`소요 수량 (L)`**, **`소요 수량 (m)`** 등으로 자동 치환
  * **장바구니 콤마 적용:** `+ 자재 목록에 추가` 버튼을 눌러 목록에 실릴 때, 숫자에 `.toLocaleString()`이 자동 매핑되어 천 단위 쉼표가 깔끔히 노출됩니다.

### 2.5. 💵 정산 및 매입 관리 (`/settlement`)
* **역할:** 자재상 지급금 및 반장님 인건비 일일 지출 내역을 매핑하여 실제 실행 예산 대비 수익성을 정산합니다.
* **상단 KPI 5대 핵심 카드시스템:**
  1. `견적 총액`: 작성된 최근 견적서 합계 금액
  2. `실제 계약금액 (수주)`: 계약 확정 합의 수주 금액
  3. `실제 수금액 (네고/할인)`: 통장 입금액 누계 + 할인/네고 삭감액 표기
  4. `실제 지출 (원가)`: 자재/외주/인건비 지출 누계
  5. `최종 순이익`: `실수금액 - 지출원가` 기반의 확정 순이익

### 2.6. 📜 현장 이력 현황 (`/settlement-history`)
* **역할:** 전체 현장의 제안(견적중)부터 수주, 공사, 완공까지의 손익 이력을 연도별로 통합 아카이빙합니다.
* **주요 기능:**
  * **동적 DB 연도 바인딩:** DB에 존재하는 연도(`availableYears`)만 콤보박스 옵션으로 실시간 동적 바인딩
  * **상단 KPI 카드 2원화:**
    * **확정 실적 카드**: 계약 체결 현장(`수주/공사/완료`)의 연간 확정 매출, 지출, 누적 순이익
    * **미계약 견적 파이프라인 카드**: `견적중` 현장의 미계약 가계산 총액
  * **통합 목록 & 상세 필터:** `전체`, `견적중`, `수주`, `공사중`, `완료` 전 현장에 대한 통합 다차원 조회 지원

### 2.7. 📂 마스터 데이터 관리 (`/master`)
* **역할:** ERP의 자재, 거래처, 공정의 마스터 기준 데이터를 관리합니다.
* **주요 기능:**
  * **자재 사전 모달 탭 분기:** 상단의 [자재 단가] 탭과 [노무/인건비 단가] 탭을 눌러, 매입원가만 입력하는 자재 등록 폼과 노무 단가만 입력하는 노무 등록 폼을 분기 처리하여 데이터 혼선을 예방합니다.
